# 16550 UART device model

The 16550 UART provides the serial console. The model is header-only, `static inline`, and has no dynamic allocation.

## Register map

| Offset  | Read                        | Write                       |
| :------ | :-------------------------- | :-------------------------- |
| `+0x00` | RBR (DLAB=0) / DLL (DLAB=1) | THR (DLAB=0) / DLL (DLAB=1) |
| `+0x01` | IER (DLAB=0) / DLM (DLAB=1) | IER (DLAB=0) / DLM (DLAB=1) |
| `+0x02` | IIR                         | FCR                         |
| `+0x03` | LCR                         | LCR                         |
| `+0x04` | MCR                         | MCR                         |
| `+0x05` | LSR                         | -                           |
| `+0x06` | MSR                         | -                           |
| `+0x07` | SCR                         | SCR                         |

The offsets are relative to the UART base. The board chooses the base and size.

## Host hooks

The board defines `RVE_DEV_UART16550_TX(byte)` before including the umbrella header. The default is a no-op. The device calls the hook on every THR write.

The board pushes received bytes with `uart16550_rx_push`. The device owns the 16-byte RX FIFO.

## Access widths

A THR write accepts any length and uses the lowest byte. This lets the ACT console write a word and Linux write a byte. All other registers require a length of one; other lengths are ignored.

## Line status

`LSR` bit 0 is data ready, bit 1 is overrun, bit 5 is THR empty and bit 6 is transmitter empty. The transmitter bits are always set because transmission is instantaneous. A read of `LSR` clears the overrun bit.

With the FIFO disabled, an overrun overwrites the single received byte. With the FIFO enabled, an overrun drops the new byte and leaves the FIFO unchanged.

## FIFO and interrupts

`FCR` bit 0 enables the FIFO. With the FIFO disabled the depth is one. A write to `FCR` affects the other bits only when bit 0 is set. Changing bit 0 resets both FIFOs. `FCR` bit 1 clears the RX FIFO and bit 2 clears the TX FIFO; both clear bits are self-clearing. Bits 6-7 select the RX trigger level: 1, 4, 8 or 14 bytes.

`IER` bits 4-5 read as zero. `MCR` bits 5-7 read as zero. `MCR` bit 3 is the global interrupt enable.

`IIR` reports the highest-priority pending interrupt: line status (`0x06`), RX data (`0x04`), character timeout (`0x0C`), THR empty (`0x02`) or none (`0x01`). Bits 7-6 report whether the FIFO is enabled. A read of `IIR` clears a pending THR-empty interrupt.

`uart16550_irq_pending` returns true when `MCR` bit 3 is set and an enabled interrupt source is pending. The board bridges it into `mip` or a platform interrupt controller.

## Known deviations

- The character timeout fires as soon as the FIFO holds fewer bytes than the trigger level. The datasheet waits four character times.
- Loopback mode (`MCR` bit 4) is not implemented.
- The prescaler (`PSD`), DMA signalling and the modem status interrupt are not implemented.
- Parity, framing and break detection are not implemented; the matching `LSR` bits read zero.

## API

| Function                | Purpose                                                |
| :---------------------- | :----------------------------------------------------- |
| `uart16550_init`        | Initializes the instance and its base and size.        |
| `uart16550_read`        | Reads a register and returns false outside the range.  |
| `uart16550_write`       | Writes a register and returns false outside the range. |
| `uart16550_rx_push`     | Pushes one received byte into the RX FIFO.             |
| `uart16550_irq_pending` | Returns true when an enabled interrupt is pending.     |

## Constraints

- No `stdio` in the library.
- No `malloc`.
- No function pointers.
- The board owns the host I/O and the interrupt bridge.
